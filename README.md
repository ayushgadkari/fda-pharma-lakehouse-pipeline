
# 💊 FDA Drug Safety Lakehouse Pipeline (Medallion Architecture)

An end-to-end Data Lakehouse solution built on **Databricks** and **PySpark** using **Delta Lake**. This pipeline ingests, cleanses, standardizes, and models semi-structured **FDA Adverse Event Reporting System (FAERS)** safety datasets using a **Medallion Architecture (Bronze → Silver → Gold)** and a **Star Schema** dimensional design.
